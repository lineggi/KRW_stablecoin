# 원화 스테이블코인 활용 시뮬레이터 (KRWT)

원화 스테이블코인(KRWT)이 **개인 일상 · 기업/가맹점 · 글로벌 송금**에서 실제로 어디에 어떻게 쓰일지를
장면(scene) 단위로 따라가는 인터랙티브 시뮬레이터입니다. 매 장면마다 *기존 방식과 무엇이 다른지*,
그리고 *백단에서 실제로 무슨 일이 일어나는지*(결제 → 온체인 전송 → 환매/정산)를 함께 보여줍니다.

> 의존성 없는 **단일 HTML 파일**입니다. `index.html`을 브라우저로 열거나 GitHub Pages로 바로 배포할 수 있습니다.

## 데모

- **허브** → 3개 모드 선택
  - 🧑 **개인 일상 (B2C)** — 카페 QR 결제 · 더치페이 · 해외직구 · 구독 자동결제 · 유휴 잔액 어닝
  - 🏪 **기업·가맹점 (B2B)** — 실시간 매출 정산 · 직원 급여 일괄지급 · 공급사 조건부 에스크로 · 트레저리 운용
  - 🌏 **글로벌 송금·무역** — 해외 가족 송금 · 무역 대금(L/C 대체 에스크로) · 환율 고정 · 글로벌 잔액 운용

각 장면은 결과(잔액 변화), 기존 방식 대비 비교(VS 카드), 그리고 일부 장면은
"실제 운영 방법 보기"로 결제·정산·환매의 단계별 흐름을 펼쳐 보여줍니다.

## 설계 포인트

- **경험 우선 설계**: 사용자는 QR 한 번/탭 한 번만 하고, 가스리스·즉시정산·환매 같은 복잡성은 뒤로 숨김
- **기존 대비 가치 명시**: 카드 T+2 정산, SWIFT 2~3일, 환전 수수료 등 *현행 마찰*과 직접 비교
- **프로그래머블 머니**: 조건부 에스크로, 잔액 기반 자동결제, 리워드형 어닝 등 스테이블코인 고유 기능 시연

## 실행

```bash
# 그냥 파일 열기
open index.html            # macOS
# 또는 로컬 서버
python3 -m http.server 8000   # http://localhost:8000
```
